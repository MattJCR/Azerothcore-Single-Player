# Contributing — Contribuir

**[Español](CONTRIBUTING_ES.md)** · **[English](CONTRIBUTING_EN.md)**

---

## Español

Las contribuciones llegan como *pull request* contra `main`, se revisan una a una y
siguen las reglas del proyecto. Un pull request **no puede modificar el cliente
sintético** (`tools/cliente-sintetico/`): sólo se aceptan los que añaden
comprobaciones nuevas, aparte y verificadas.

➡️ **[Leer cómo contribuir](CONTRIBUTING_ES.md)**

---

## English

Contributions arrive as pull requests against `main`, are reviewed one by one and
follow the project's rules. A pull request **cannot modify the synthetic client**
(`tools/cliente-sintetico/`): only those that add new checks, separately and
verified, are accepted.

➡️ **[Read how to contribute](CONTRIBUTING_EN.md)**
